💡 Pro Tip: Drag the "Start Analytics Portal" button to your bookmarks bar, or bookmark this page for instant access!

📋 First-Time Setup:

  1. Open Terminal in the project folder
  2. Run: ./create-url-handler.sh
  3. Click the "Start Analytics Portal" button above
  4. Allow the protocol handler when prompted
  5. The server will start and your browser will open automatically!

🎯 How It Works:

  1. Click the link above (or your bookmark)
  2. macOS opens the custom analytics:// protocol
  3. Terminal launches and runs the start script
  4. Server starts on port 3000
  5. Browser automatically opens to localhost:3000
